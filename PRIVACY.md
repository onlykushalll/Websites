# Privacy Policy — Websites Showcase

**Last Updated:** September 7, 2026

This repository hosts static frontend design concepts, creative web demonstrations, and portfolio showcases created by Kushal (onlykushalll).

---

## 1. Zero Tracking & No Cookies

- **No Cookies:** None of the static websites in this monorepo set tracking, analytics, or advertising cookies.
- **No Telemetry:** We do not track your IP address, browser fingerprint, or geographic location.
- **Static Delivery:** All HTML, CSS, JavaScript, and asset files are served statically with zero backend user profiling.

---

## 2. Contact Forms & Inquiries

If a showcase includes an interactive demo form, data submitted is either:
- Processed purely in client-side memory for demonstration purposes, or
- Dispatched directly via secure email service with no third-party data broker sharing.
