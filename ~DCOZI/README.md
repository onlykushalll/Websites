# Dcozi Enterprises — Smart Signage & Digital Podiums

Dcozi Enterprises is India's leading manufacturer of high-end digital podiums, interactive kiosks, smart signage solutions, and heavy-duty industrial smart locker systems. 

This repository hosts the official landing page for **Dcozi Enterprises**, designed to represent its luxury hardware offerings with a clean, performant, and premium digital interface.

---

## ✨ Features

- **Modern Responsive Layout**: Scaled layouts designed with React, Vite, and Tailwind CSS.
- **Lenis Smooth Scroll**: Silky smooth scroll behavior with inertia support across desktop browsers.
- **Interactive Product Showcase**: Custom product carousel displaying advanced digital podium features and configurations.
- **Form Interactivity**: Sleek user inquiry form for custom design estimates and specifications.
- **Fast Performance**: Font preconnecting, optimized styling, and clean state lifecycles.

---

## 🛠️ Tech Stack

- **Core Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Language**: TypeScript

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed.

### Installation

1. Navigate to the project directory:
   ```bash
   cd ~DCOZI
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. Build the application for production:
   ```bash
   npm run build
   ```
   The static distribution files will be generated in the `dist` directory.
