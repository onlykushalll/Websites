# Contributing to Web Experience Showcase

Thank you for your interest in contributing! We aim to maintain a high level of code quality, visual aesthetics, and performant design systems.

---

## 🛠️ Development Guidelines

### 1. Code Quality & Standards
- Keep your components modular, clean, and reusable.
- Follow standard TypeScript linting guidelines.
- Do not commit local configuration files, secret API keys, or build artifacts (`dist`, `.next`).
- Do not introduce AI brand logs, contributions, or references to other platforms unless explicitly specified.

### 2. Styling & Animation Constraints
- Prioritize CSS custom properties and standard animation frameworks (Framer Motion, GSAP, Tailwind CSS).
- Ensure all hover effects, transitions, and layout adjustments have a smooth aesthetic feel.
- Verify responsiveness across mobile, tablet, and desktop viewports.

---

## 🚀 Branching & PR Guidelines

1. **Create a Topic Branch:**
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. **Commit Your Changes:**
   Use clean commit messages like:
   - `feat(components): add immersive particle dust to hero`
   - `fix(styling): align navbar for mobile viewports`
3. **Open a Pull Request:**
   Provide a detailed description of your changes, and attach screenshots or screen recordings if there are any visual modifications.
