# Be My Valentine? — Interactive Valentine Experience

An interactive, beautifully animated website to ask your crush to be your Valentine featuring dynamic buttons, cute transitions, and a date planner.

## Features

- Interactive "Will You Be My Valentine?" proposal flow
- Dynamic response handling and playful interactive elements
- Custom date planner and memory card components
- Responsive, modern design with fluid animations

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`

2. Run the development server:
   `npm run dev`

3. Build for production:
   `npm run build`
